# Brand assets

Original supplied logo files, kept here as the source of truth.

- `451-badge-original.png` — the badge on black
- `451-badge-alt-original.png` — alternate version

The web-ready cutouts live in `public/brand/`:

- `logo-glow.webp` / `logo-glow.png` — the badge with its black background
  converted to real transparency, so it composites onto photography with no
  square edge. Generated from the original with alpha derived from luminance.
- `logo-dark.png` — the original, retained for the favicon and social preview
  image where a solid background is fine.
